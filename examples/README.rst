Examples Gallery
================

Short, executable examples that follow the workflow of the library:
reading and rendering ECG records, preprocessing, online data augmentation,
building a dataset and drawing a batch, assembling models, and training and
evaluating a small classifier.  Every example runs on the sample data
bundled in this repository and produces its figures at documentation build
time.  The examples are minimal; complete training pipelines, one per
challenge database, are maintained separately in the ``benchmarks/``
directory of the repository.
