Examples#

The benchmarks/ directory of the repository contains eight complete, self-contained training examples – one per challenge / database – written against the modern library API. They double as the reference usage examples for the whole package: each one shows reader and dataset usage, model construction, training with the library trainer, and evaluation with the official challenge metrics where applicable.

Each benchmark is runnable as a module with a --smoke debug mode (a few hundred iterations on a subset, no full training):

python -m benchmarks.train_crnn_cinc2021.train --help
python -m benchmarks.train_crnn_cinc2021.train --smoke

Highlights to look for#

  • Determinism: every train.py calls seed_everything() and uses worker_init_fn; a given --seed fully determines the run.

  • Library datasets/readers/metrics: the examples consume torch_ecg.databases readers and datasets instead of local copies, and compute official challenge metrics via the library.

  • Offline preparation: train_hybrid_cpsc2021 runs the (idempotent) offline preparation via persistence() automatically.

  • Checkpoints: written via save() with the full model config, loadable with from_checkpoint().

Tests of the examples#

test/test_pipelines/ contains thin pytest wrappers over the benchmarks (fast lanes run the non-downloading parts; the nightly full suite trains briefly on real data), so the examples are continuously verified against the library.
