User Guide
==========

This guide walks through the package the way you would use it: read a
database, wrap it in a dataset, pick and configure a model, train it
with the library trainer, and evaluate with (official) metrics.

.. toctree::
   :maxdepth: 1

Every code block in this guide is either executed as part of the test
suite or lifted from the :ref:`examples <examples>` (the `benchmarks/
<https://github.com/DeepPSP/torch_ecg/tree/master/benchmarks>`__
directory), which double as continuously-tested reference usage.
